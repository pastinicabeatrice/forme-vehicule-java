# Forme și vehicule

Exerciții de laborator pentru programarea orientată pe obiecte în Java.

## Ce conține

- `lab` - clasa abstractă `Shape` cu `Circle`, `Rectangle` și `Triangle`, plus `Vehicle` cu `Car`, `Bike` și `Boat` (moștenire și polimorfism)
- `compozition` - compunere: `Car` care conține un `Engine`
- `arrayList` - lucrul cu `ArrayList`
- `wrapperClass` - clasele wrapper (`Integer`, `Double` etc.), autoboxing și unboxing

## Rulare

Se deschide folderul în IntelliJ IDEA și se rulează clasa `Main` din pachetul dorit.
